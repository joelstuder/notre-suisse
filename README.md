# Notre Suisse

Calendrier de l'Avent en 3D : 24 lieux en Suisse, une photo cachée par jour et un message secret à reconstituer.

- Carte : © swisstopo, tuiles vectorielles chargées en direct (toute la Suisse, zoom maximal, bâtiments 3D)
- Relief : Mapzen / AWS Terrain Tiles
- Moteur : MapLibre GL JS
- Photos des lieux : Wikimedia Commons (auteur et licence sous chaque photo)

Aperçu (tout débloqué, pour tester) : ajouter `#apercu` à la fin de l'adresse.
